# Contents

- `history/*.yml` – authored category metadata and source-linked events served by the website.

# Guidelines

- Keep one file per canonical category and retain the `stripe-guide/history/v1` compatibility schema identifier.
- Give every event a globally unique stable ID and at least one direct source URL.
- Prefer primary sources. Preserve source titles, publishers, publication dates, confidence, and transaction status exactly enough to support the summary.
- Review chronology, duplicates, category placement, and uncertainty before committing data changes.
